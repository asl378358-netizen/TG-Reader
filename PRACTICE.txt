Практические варианты — проверка 5 октября 2026

Выбранный путь: свой Windows-сборщик + локальный Telegram Desktop
----------------------------------------------------------------
opentele2 — продолжение библиотеки конвертации Telegram Desktop tdata
в Telethon. Автор сообщил о возобновлении поддержки на Reddit 7 февраля
2026. Релиз 1.2.1 содержит исправления формата tdata и зависимости TgCrypto.
Это заявление автора и проверяемый код, не независимый отчет о работе
на нашем аккаунте. В этом пакете используется точная версия 1.2.1.

Reddit: https://www.reddit.com/r/TelegramBots/comments/1qyf510/opentele2_new_era/
Код: https://github.com/DedInc/opentele2
Релизы: https://github.com/DedInc/opentele2/releases
Пример: https://opentele2.github.io/examples/convert-tdata-to-telethon/

В нашем коде отключены сторонние запросы за версиями и автоматические
post-login действия библиотеки. Случайные устройства не генерируются.
Библиотека используется для чтения локального собственного Desktop-сеанса.
Новый отдельный сеанс создаёт наш код; его подтверждение проверено
тестом на порядок регистрации обработчика QR. Реальный вход еще нужен.
Используются встроенные API-реквизиты Desktop. Это снимает зависимость от
регистрации на my.telegram.org, но не гарантирует принятия входа Telegram.

Что посмотрено дополнительно
----------------------------
1. deathmaz/tg-export:
https://github.com/deathmaz/tg-export
В README есть частные группы, медиа, --last 24h и контрольные точки.
В auth.py встроены API-реквизиты, свои ключи необязательны. Пара 611335
встречается в сборках Telegram Desktop для Linux. Это еще одна реальная
реализация подхода со встроенной идентичностью приложения.
Проверены cli.py, auth.py и fetcher.py; на нашем аккаунте не запускалось.
Это HTML-экспортер, а не полный обработчик форумных тем для нашей задачи.

2. DLHellMe/telegram-mcp-server:
https://github.com/DLHellMe/telegram-mcp-server
В README заявлены API-режим и браузерный режим без ключей.
Проверен src/scraper/telegram-scraper.ts. Есть попытки авторизованного
Telegram Web, поиск по имени, сохранение cookies и переходы к публичным
t.me-превью при неудаче. Код содержит частный заранее известный ID канала.
Это не доказательство надежного сбора 10 частных форумов со всеми медиа.
Поэтому проект не используется как готовая основа нашего пакета.

3. agentcooper, Telegram chat backup/export:
https://gist.github.com/agentcooper/b5c0cec210bd81c6b49a6385f9d66069
Настоящий браузерный экспорт без собственного API-приложения существовал.
Этот конкретный скрипт использует старый Angular/Webogram; в комментариях
есть angular is not defined и совет переключиться на старую версию.
Дата последней активности страницы не означает обновление скрипта.
Для современной версии Telegram Web потребуется новый адаптер;
этот старый код не входит в пакет и не предлагается к запуску.

Как люди строят обработчик
--------------------------
На Medium прочитан опыт Denis Kolenko:
70 Sources, One Telegram Channel: Building an AI News Pipeline with Local LLMs
23 марта 2026.
https://medium.com/@deniskolenko04/70-sources-one-telegram-channel-building-an-ai-news-pipeline-with-local-llms-33cfd0beb8e7

Автор описывает Telethon для источников Telegram, SQLite для состояния,
фильтрацию, объединение повторов и отдельный вечерний дайджест.
Это авторский рассказ про новостные источники, а не проверенная реализация
нашего частного учебного форума. Он использует локальные модели и
обученный фильтр; мы не переносим эту сложность в первую версию.

Для нашей задачи: сначала сохранить весь доступный поток. Объединить
сообщения по настоящему ID темы, связи ответа и альбому. Добавить
транскрипт речи и изображения. Затем GPT оценивает обсуждение целиком:
решения, инструкции, материалы, объявления, вопросы без ответа.
Короткий ответ может быть важен вместе с вопросом — его нельзя заранее
выкинуть как «шум». Сводка должна давать ссылки и явно показывать неполноту.
Повторы при сборе устраняются по chat ID + message ID; сходство текстов
не служит поводом удалять исходные сообщения.

GPT обрабатывает подготовленные материалы из Drive после проверки доступа
и первого ручного результата. Оплачиваемый AI API в этом пакете не нужен;
распознавание речи выполняется локально. Расписание GPT еще не подключено.
