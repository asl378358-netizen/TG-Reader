TG Reader

Сообщения, фотографии, голосовые и кружочки выбранных Telegram-групп собираются в папку Google Диска. Голосовые расшифровываются локально. Полноформатные видео пропускаются.

Установка один раз

  1. Скачай и запусти TG-Reader-Setup.cmd. Он использует уже установленный Python; новая копия Python не скачивается.
  2. Запускай постоянный ярлык TG Reader на рабочем столе или в меню «Пуск».
  3. Закрой Telegram Desktop через значок возле часов → Выход. VPN/прокси оставь работающим.
  4. В окне программы нажми «Подключить Telegram / выбрать группы». Выбери tdata, свой аккаунт, одну группу и папку Google Диска.
  5. Нажми «Собрать сейчас» и «Открыть состояние». Проверь файлы в браузерном Google Диске. После проверки можно включить автосбор.

Обновления

При запуске ярлыка программа проверяет ветку stable в GitHub. Новая версия проверяется до переключения; предыдущая версия и локальные данные сохраняются. Ошибка сети не мешает работе установленной версии.

Репозиторий приватный. Для обновления программа использует уже сохранённый доступ GitHub CLI или Git Credential Manager. Если доступа нет, она сообщает причину и открывает установленную версию. Коннектор ChatGPT не передаёт авторизацию приложению Windows. Новое окно входа в браузере не открывается.

Данные и помощь

Настройки, сеанс, база сообщений и журналы находятся в %LOCALAPPDATA%\TelegramDailyReader. Старую распакованную папку на рабочем столе можно убрать. Папку AppData оставь: в ней данные.

Кнопка «Открыть журналы» показывает setup.log, launcher.log, collector.log и last-collection.log. При ошибке установки окно остаётся открытым. Для восстановления можно повторно запустить сохранённый TG-Reader-Setup.cmd.

Ежедневную задачу ChatGPT подключаем после первого успешного сбора и синхронизации. Сам установщик её не создаёт.
