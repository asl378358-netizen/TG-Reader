TG Reader 0.3.1 — один установочный файл и постоянный ярлык

1. Скачать TG-Reader-Setup.cmd и запустить двойным щелчком.
   Установщик использует существующий Python, нового Python не скачивает.
   Настройки и авторизация в AppData сохраняются.
2. Дальше запускать ярлык TG Reader на рабочем столе.
3. Закрыть Telegram Desktop через значок возле часов → Выход.
   Прокси/VPN оставить работающим.
4. В окне программы нажать «Подключить Telegram / выбрать группы».
   Выбрать tdata, свой аккаунт, одну группу и папку Google Диска.
   Без локальной блокировки Desktop код не запрашивается.
   Если tdata не открылась без кода, нужен локальный код блокировки этого ПК.
   Облачный пароль Telegram запрашивается отдельно после выбора аккаунта.
   Пароль виден по умолчанию; можно скрыть, вставить из буфера.
5. Нажать «Собрать сейчас», затем «Открыть состояние».
   Проверить появление файлов в браузерном Google Диске.
6. После успешного сбора можно включить автосбор.

Обновления проверяются из ветки stable автоматически. Для приватного
репозитория нужен уже сохранённый доступ GitHub на Windows. Коннектор
ChatGPT не передаёт этот доступ приложению. Без него установленная
версия продолжает работать, а причина видна в окне и launcher.log.
Новый вход в браузере программа не открывает.

Не нужно вручную распаковывать ZIP или запускать старые update CMD.
Журналы и резервная копия установщика:
%LOCALAPPDATA%\TelegramDailyReader
Полная инструкция: README.md.
